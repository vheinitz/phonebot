Blöcke werden über Einrückung gebildet (wie in Python): eine Kopfzeile endet mit :, der Körper steht eingerückt darunter. Für einen kurzen Einzeiler dürfen die Anweisungen auch mit ; hinter dem : stehen. # leitet einen Kommentar ein.

loop:
  mot.left = 95
  mot.right = 95
  if cam.line.lost:
    mot.left = 0
    mot.right = 0

Abschnitte / Ereignisse (nur ganz links):

start:läuft einmal beim Start (Variablen vorbelegen)
loop:läuft in jedem Takt (Hauptschleife)
key w:wenn Taste w gedrückt wird (z. B. BT-Tastatur)
bstop:wenn der Stopp-Knopf gedrückt wird (hält danach an)
bat_low:wenn der Akku schwach wird

Steuerung & Werte:

mot.left = …Motor setzen (−255…255, − = rückwärts)
speed = 120eigene Variable (merkt sich Werte über Takte)
if … : / else:Verzweigung
for i = 1 to 5:Zählschleife (synchron, zum Rechnen)
stopProgramm anhalten
and or not < > == …in Bedingungen; Rechnen mit + - * /
